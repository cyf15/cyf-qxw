# 项目约定

- 当前只面向 Windows 开发与验收。用户已将 macOS 适配延后到 `G:/aut lab/TODO.md`，暂不开展 Mac 适配或测试；跨平台支持不作为当前交付前置条件。

- 开发优先。Project 1/2 只作为后续提交材料与任务清单，报告、图表、反思、视频等后补，不作为开发前置条件；不得因课程指定 Derby、JUnit 4 或材料顺序限制当前实现。用户明确要求的游戏玩法、双界面、架构、持久化与测试仍有效。

- 需求基线见 `G:/aut lab/需求文档.md`。用户明确规定优先；未提及的玩法、数值与结算细节全部按照一代源码，不自行设计替代规则。
- 不可改动的核心玩法是同机本地 hotseat PVP：两名玩家各控制一名角色，交替进行回合。适配源码不能改为单人打怪、AI 对手、联网或同时行动。
- 用户已明确授权 libGDX 与源码复用，不因课程规则停止开发或重复索要确认；该授权不代表老师确认课程合规。

- 工作目标目录为 `G:/aut lab`，新工作放在该目录及其子目录，不在二代 Steam 安装目录开发。
- 使用 Java + libGDX；不自行切换到 Godot、C#、Swing 或 JavaFX。
- 游戏方向为杀戮尖塔一代风格的本地 PVP。以一代全部元素为参考范围，包括角色、卡牌、遗物、药水、状态、战斗、地图、事件和界面；这不表示这些功能已经实现。按用户指定的阶段逐步交付。
- 优先检查一代已有代码和架构，沿用适合的类职责、行动队列、卡牌效果与状态结算设计。涉及 PVP 时明确双方玩家、目标、回合和胜负规则，不能把怪物对象直接当作玩家而忽略原有假设。
- 已找到的一代参考工程为 `https://github.com/Li-Binghui/MySlayTheSpire`，它是反编译并修改过的工程，不是官方原始源码；使用前核对实际文件和版本。不要将仅存在于远端的代码声称为本地已安装。
- 素材选择必须先读取并遵循 [reuse-source-assets](../reuse-source-assets/SKILL.md)。优先复用一代源码工程现有素材，保留来源；不得自行生成新素材。
- 保留目录中已有工作。未经用户要求，不删除旧项目，不覆盖游戏安装文件或存档。
