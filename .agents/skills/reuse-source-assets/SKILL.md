# 本项目素材规则

仅适用于 `G:/aut lab` 项目及其子目录。

- 使用素材前，先检查项目源码、资源目录及现有素材引用，优先复用源码中已有的素材。
- 不得自行生成新素材，包括调用 AI 图片、音频或模型生成工具，以及通过代码绘制替代素材。
- 可以按实现需要引用、复制或调整已有素材的尺寸、裁剪和格式，保留素材来源。
- 如果现有素材不能满足需求，说明缺少的素材并等待用户提供或明确指定处理方式；不得自动转为生成素材。
